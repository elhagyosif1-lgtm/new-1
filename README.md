# Coin Center Pro

Independent Arabic-first coin recharge center foundation. Not an official TikTok portal. No live payments or fulfillment until a persistent isolated database, licensed payment provider, and authorized supplier API are configured.

## Run
Node.js 20+, `npm install`, configure `.env.local`, then `npm run dev`.

## Launch gates
- Isolated persistent database and per-user access policies.
- Verified authentication.
- Licensed payment provider with server-side webhook verification.
- Authorized supplier contract/API.
- Audit trail, reconciliation, refunds, and security tests.

No fake balances, payment confirmations, or delivery claims.

Vercel framework configured as Next.js; output directory is auto-detected.
